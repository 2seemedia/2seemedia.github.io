مسودة محلية

إدارة موقع 2See Media

يمكنك تعديل النصوص والصور وأغلفة الأعمال، إضافة الأعمال والشعارات أو حذفها، ثم معاينة التغييرات قبل نشرها على الموقع الرسمي.

عرض الموقع الرسمي ↗

الخطوات: 1. اختاري القسم وعدّلي المحتوى 2. احفظي مسودة وراجعي المعاينة 3. انشري باستخدام صلاحية GitHub

تعديل أي نص مباشرة من المعاينة

اختاري الصفحة واللغة، ثم اضغطي على أي عبارة داخل الموقع. ستظهر خصائص النص وأزرار تغييره أو إخفائه في لوحة التحكم.

انقري على نص داخل المعاينة لتعديل شكله أو محتواه، ثم اختاري «نشر الآن» بعد اعتماد التغييرات.

إظهار وإخفاء الأقسام

فيك تخفي أي قسم بالموقع أو ترجعي تظهريه. الأقسام فيها معلومات 2SEE الحالية وقابلة للتعديل.

إدارة معرض الأعمال

إضافة، تعديل، حذف، ترتيب، إخفاء وإظهار الأعمال. اختاري «مميز» ليظهر العمل على الصفحة الرئيسية.

شعارات الجهات والأشخاص الذين تعاونّا معهم

تظهر الشعارات بحجم موحّد وبحركة مستمرة أسفل الأعمال في الرئيسية وصفحة الأعمال. يمكن إضافة تعاون واحد أو أكثر، ولو كان العمل ريلًا واحدًا فقط. لن تظهر شعارات افتراضية للزوار.

الهوية والإعدادات العامة

فتح بصفحة جديدة

المعاينة تعرض المسودة من هالجهاز فقط. الموقع الرسمي ما بيتغير إلا بعد النشر.

النسخ الاحتياطي والتصدير

فيك تحمّلي ملف المحتوى، أو نسخة JavaScript جاهزة للرفع. تُحفظ مسودتك على المتصفح الحالي، ويمكنك تنزيل نسخة احتياطية لنقلها إلى جهاز آخر.

النشر الآمن

جارٍ التحقق من الجلسة…

المعاينة والمسودة لا تغيّران الموقع الرسمي. النشر التجريبي يذهب لفرع اختبار منفصل. النشر الرسمي مقفل حتى اكتمال الاختبار والموافقة.
